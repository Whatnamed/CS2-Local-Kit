## 当前 build 的停止依据

使用现有只读 PE executable-section scanner，未加载 DLL、未安装 Hook、未写入 patch：

| 扫描输入 | 结果 |
| --- | --- |
| 原包三 native gamedata 的全部 25 条 Windows signatures | 14 unique、9 missing、2 ambiguous |
| tag 全部 42 个 BotAI Windows patch definitions；其 signature 字符串均在原包 DLL 内找到 | 39 unique、2 missing、1 ambiguous；另有一个 unique 点原始 bytes 不匹配 |

native 问题横跨 Controller 的 EquipBestWeapon/EquipPistol/SelectItem/BuyState/UpdateLookAngles/SetEyeAngles、
Hider 的 MaintainBotQuota/MpHumanTeam/PackEntities、Vision 的 smoke visibility/BulletPelletTrace。
这已不是只确认一个 framework 缺项或一两个明确失效绑定的工作量。

BotAI 的 `Vision_ApproachBody_SkipSkillCheck` 在两个位置都通过 original-byte 检查，不能任选一个；
`TBot_BombsiteSearch_UseKnownPlantedSite` 在 RVA `0x32fe4c` 唯一匹配，但 patch offset 15 的原始 bytes 是
`E8 40 51 F9 FF`，旧定义期待 `E8 38 3B F9 FF`，旧 replacement 为 `E8 28 41 F9 FF`。
这是相对 CALL，不可只放宽 expected bytes 后继续使用旧 replacement；需要重新核实目标和控制流。

[native 扫描](2026-10-22-bot-v144-retest/native-signatures.json)、
[managed 扫描](2026-10-22-bot-v144-retest/managed-signatures.json)、
[47 项 native offsets](2026-10-22-bot-v144-retest/native-offsets.json) 留存输入、来源 hash、当前 binary hash、RVA 和 bytes。
附带的三个 BotState 和一个 Aim signature 在原 DLL 找到 literal；额外 `BotBlindWindowsSignature`
未在原 DLL 找到 literal，明确只算 tag-source 证据。字符串存在不能证明 DLL 的 patch offset 或全部 IL 算法相同。
未继续认证 CSS/RayTrace/其他模块和全部私有布局，也不把已扫范围当作完整安全证明。

因此按用户要求停止：不移植新版系统、不猜测 Hook、不制作安装候选、不修改既有事务工具的固定 ref 或门禁。
完整安装/失败恢复/精确回滚与真实候选安装均未进入执行阶段，不声称这些项目通过。
